Tutorials

Adding a skill

Skills are compiled from real runs; you do not write them by hand.

  1. Do the same task at least 3 times.
  2. node bin/he-server.js skills --min 3 --save
  3. Confirm it shows up in the Skills card.
  4. Later use skill_use <id>，health is recorded automatically。

Adding a card

A card is a job for the AI: steps plus acceptance checks.

  1. Copy a file in src/cards/*.json and edit id/title/goal/path.
  2. verify Add acceptance checks (file / text / screen / exit code / screen changed).
  3. It appears in the Cards card after a restart.

Installing a domain pack

A domain pack is one industry's checks plus cards.

  1. node bin/he-server.js pack validate <dir>
  2. node bin/he-server.js pack install <dir>

Moving your data

  1. node bin/he-server.js export backup.json
  2. On another machine, import backup.json
  3. Skills can also export as SKILL.md：skill export <id> --to <dir>

When the gate refuses

  • GOAL_STEP_REQUIRED: run goal_step_enter
  • PATH_DEVIATION: run episode_checkpoint
  • CONFIRM_REQUIRED: open "Pending confirmation" on the right and allow it once
  • STEP_BUDGET_EXCEEDED: goal_step_continue explain why

Reading the log

  • Levels: 1 Critical / 2 Error / 3 Warning / 4 Information / 5 Verbose
  • Event IDs: 2xxx gate, 3xxx goal, 4xxx action, 5xxx skill
  • Click any row for details; CSV export is available.
