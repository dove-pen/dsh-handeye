教程

怎么加一份技能

技能从真实操作里编译，不用手写。

  1. 做同一件事 3 次以上。
  2. node bin/he-server.js skills --min 3 --save
  3. 到"技能"卡里确认它出现。
  4. 以后用 skill_use <id>，跑完自动记账。

怎么加一张任务卡

任务卡是"给 AI 的活"，带步骤和判据。

  1. 复制 src/cards/*.json，改 id/title/goal/path。
  2. verify 写验收判据（文件/文本/屏幕/退出码/画面变化）。
  3. 重启插件后出现在"任务卡"卡里。

怎么装一个领域包

领域包 = 一整个行业的判据 + 卡片。

  1. node bin/he-server.js pack validate <目录>
  2. node bin/he-server.js pack install <目录>

怎么把数据带走

  1. node bin/he-server.js export backup.json
  2. 换机器后 import backup.json
  3. 技能还能导出成 SKILL.md：skill export <id> --to <目录>

门卫拦住了怎么办

  • GOAL_STEP_REQUIRED：先 goal_step_enter
  • PATH_DEVIATION：先 episode_checkpoint
  • CONFIRM_REQUIRED：到右侧"待确认"点允许一次
  • STEP_BUDGET_EXCEEDED：goal_step_continue 说明理由

日志怎么看

  • 级别：1 严重 / 2 错误 / 3 警告 / 4 信息 / 5 详细
  • 事件 ID：2xxx 门卫、3xxx 目标、4xxx 动作、5xxx 技能
  • 点任意一行看详细信息；可导出 CSV。
