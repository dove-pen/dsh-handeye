怎么加一份技能

技能从真实操作里编译，不用手写。

  1. 做同一件事 3 次以上（同一套工具、同一套步骤）。
  2. 跑 node bin/he-server.js skills --min 3 --save。
  3. 到"技能健康度"里确认它出现了。
  4. 以后用 skill_use <id>，跑完会自动记账。

怎么加一张任务卡

任务卡是"给 AI 的活"，带步骤和判据。

  1. 复制一份 src/cards/*.json 改 id/title/goal/path。
  2. verify 里写验收判据（文件/文本/屏幕/退出码/画面变化）。
  3. 重启插件后出现在"任务卡"页。

怎么装一个领域包

领域包 = 一整个行业的判据 + 卡片。

  1. node bin/he-server.js pack validate <目录>
  2. node bin/he-server.js pack install <目录>
  3. 卡片会出现在"任务卡"页。

怎么把数据带走

技能、目标、卡片都可以打包成一个文件。

  1. node bin/he-server.js export backup.json
  2. 换机器后 import backup.json
  3. 技能还能导出成标准 SKILL.md：skill export <id> --to <目录>

门卫拦住了怎么办

被拦是设计，不是故障。

  • GOAL_STEP_REQUIRED：先 goal_step_enter。
  • PATH_DEVIATION：连做 3 个动作了，先 episode_checkpoint。
  • CONFIRM_REQUIRED：破坏性动作，到"待确认"里点允许（只在这一次有效）。
  • STEP_BUDGET_EXCEEDED：这一步动作太多，goal_step_continue 说明理由。

日志怎么看

"系统日志"页按 Windows 事件查看器的列排。

  • 级别：1 严重 / 2 错误 / 3 警告 / 4 信息 / 5 详细
  • 事件 ID：2xxx 门卫、3xxx 目标、4xxx 动作、5xxx 技能
  • 点任意一行看详细信息；可导出 CSV。
